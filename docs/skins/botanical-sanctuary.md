# 植物秘境

## 一句话概念

把牌中的力量理解成一座花园：有萌芽与盛放，也有修剪、休眠和重新扎根。

## 视觉语言

- 枝叶走势表达能量方向，花果状态表达阶段。
- 根、藤蔓、刺与种子分别对应基础、牵连、防御与潜力。
- 季节变化用于表现时间感，但不把未来写成确定结果。

## 牌背逻辑

循环生长的纹样让牌背呈现连续性，提醒用户每次提问只是成长过程中的一个切面。

## 牌面逻辑

植物状态需要忠于原牌含义：过度缠绕可以是束缚，必要修剪可以是边界，休眠也可能是恢复，而不是失败。

## 解读气质

适合长期成长、工作节奏与身心恢复。建议应重视过程、环境和可持续性，避免空泛地要求用户“积极成长”。
