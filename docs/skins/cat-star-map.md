# 猫咪星图

## 一句话概念

让猫成为牌中安静的观察者：它不替人作决定，却总能发现房间里最细微的情绪变化。

## 视觉语言

- 奶油粉、月光金与墨色形成柔和而有辨识度的主色。
- 猫的目光、尾巴和身体朝向承担原牌人物姿态的叙事功能。
- 月相与星点连接不同牌面，让整套牌像同一片夜空中的片段。

## 牌背逻辑

重复的猫与星月图案弱化单张牌的方向提示，保留抽牌的未知感；温暖的颜色降低第一次使用塔罗时的距离感。

## 牌面逻辑

改编牌面时优先保留原牌最重要的象征关系，而不是只替换角色。例如“女祭司”仍需表现边界、隐藏知识与内在聆听；猫的安静注视只是这层牌义的新表达。

## 解读气质

适合日常问题、自我关怀和关系中的细微感受。文字可以温柔，但不能因为画面可爱而淡化冲突、边界或风险。
