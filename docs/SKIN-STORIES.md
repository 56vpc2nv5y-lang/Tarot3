# VELA 皮肤设计故事

这份文档同时作为皮肤商店中“设计故事”的内容依据。牌背负责营造抽牌前的氛围，牌面负责承载翻牌后的象征；两者可以分别装备。

## 猫咪星图

详细设计稿：[猫咪星图](skins/cat-star-map.md)

- **核心意象**：猫、月相、安静的好奇心。
- **牌背思路**：重复排列的猫与星月让每一张尚未翻开的牌都像一扇仍在观察你的窗。
- **牌面思路**：保留原牌的构图与象征关系，用猫的姿态重新表达人物的警觉、亲近、犹豫和勇气。
- **适合场景**：日常问题、自我关怀、关系中的细微感受。
- **设计原则**：可爱不等于削弱含义；没有完成专属牌面的牌，会回退到经典牌面，保证牌义和功能可用。

## 神谕微光

详细设计稿：[神谕微光](skins/divine-glimmer.md)

- **核心意象**：光、神殿、仪式与命运的回声。
- **牌背思路**：让抽牌像把手伸入尚未命名的夜色，强调仪式感与未知感。
- **牌面思路**：加强大阿尔卡纳与关键人物牌的神圣感，用光源、姿态和空间层次突出原有象征。
- **适合场景**：人生方向、阶段转折、价值选择。
- **设计原则**：视觉可以宏大，解读仍应落到具体处境与可执行建议。

## 植物秘境

详细设计稿：[植物秘境](skins/botanical-sanctuary.md)

- **核心意象**：植物、生长周期、季节与疗愈。
- **牌背思路**：以枝叶和花朵形成自然循环，象征问题并非静止，而是在萌芽、盛放或凋落中变化。
- **牌面思路**：用植物状态对应牌的能量流动，例如扎根、缠绕、开花、结果与休眠。
- **适合场景**：长期成长、工作节奏、身心恢复。
- **设计原则**：避免把“成长”写成单向乐观；枯萎、修剪和休眠同样具有必要性。

## 共通使用规则

1. 牌背与牌面独立选择，换牌背不会覆盖牌面选择。
2. 专属牌面缺失时自动使用经典韦特牌面，不显示空白，也不错误显示牌背。
3. 逆位只旋转牌面图像，牌名、牌位和交互区域保持正向可读。
4. 皮肤只改变视觉表达，不改变抽牌概率、牌义、积分和成就判定。
